Inline edit interaction pattern

Once the user clicks the pencil icon, how does the edit work?

A — Input with confirm / cancel buttons

Pencil click replaces the value with a number input and two icon buttons. Click ✓ or press Enter to commit. Click ✗ or press Esc to revert. Explicit affordance — nothing surprising.

days
Press Enter or click away to commit. Press Esc to revert. No extra buttons.
⚠ "click away to commit" can be surprising — fat-finger navigation triggers an unwanted commit

B — Keyboard-only (Enter / Esc / blur)

No buttons. Enter or blur commits. Esc reverts. Minimal chrome, but blur-to-commit is a common source of accidental edits — clicking somewhere else on the page silently updates the value.

In both patterns, when a non-default value is active, a small indicator appears next to the value to signal it has been overridden (e.g. a pencil icon tint or a subtle "edited" dot).
