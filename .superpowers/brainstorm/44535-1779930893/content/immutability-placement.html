A pencil icon sits next to the "30 days" value. Clicking it replaces the display with an inline number input + confirm/cancel. Feels contextual and direct — the edit is right where the value lives.

Trade-offs

Settings dialog

  • Consistent with all other overrides
  • Active settings badge provides visibility
  • Persisted across sessions (localStorage)
  • Less code — existing patterns

Inline pencil

  • Discoverable — edit is next to the value
  • No dialog round-trip needed
  • Clear visual that this field is different from the others (it's derived, but overridable)
  • More code — new inline-edit pattern
